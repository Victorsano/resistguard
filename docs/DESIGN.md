# ResistGuard visual identity

Direction: a practical medicine-literacy field guide. Borrow from printed package labels, reference manuals and editorial layouts.

- Ink #18202d, paper #f3f2ec, cobalt #254cce, orange #f56d47.
- Bold sans-serif headings; monospace metadata and numbered steps. Body text uses a familiar system font without external font requests.
- Flat surfaces, rules and small corner radii. Orange highlights context; cobalt marks actions and links.
- R/G monogram and an illustrated ingredient-panel specimen replace the ornamental shield/capsule hero. Specimen is explicitly an illustration, not a medicine label.
- Direct copy centred on reading ingredients and asking a pharmacist. No clinical approval or impact implied by visual treatment.
- Mobile navigation scrolls horizontally instead of shrinking all labels. Keep consent, input labels, source links and safety text readable.

Implementation: shared styling in app/polish.css, with existing scan/camera/pilot behaviour preserved. No generated brand photography or decorative motion added.
